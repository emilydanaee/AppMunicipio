# Checklist de prueba MAUI

## Preparación

- [ ] La API queda abierta en `http://localhost:5279`.
- [ ] Swagger abre en `http://localhost:5279/swagger`.
- [ ] MAUI abre con Windows Machine.
- [ ] La pestaña Módulos muestra los tres módulos.

## Administrador

Iniciar sesión con `admin@quito.gob.ec` / `Admin123`.

- [ ] Crear, editar y eliminar un taller.
- [ ] Crear, editar y eliminar una feria.
- [ ] Crear, editar y eliminar una campaña.
- [ ] Consultar inscritos de un taller.
- [ ] Cambiar el estado de un reporte.
- [ ] Cambiar o cerrar un caso de calle o violencia.
- [ ] Consultar el panel estadístico.

## Ciudadano

Iniciar sesión con `ciudadano@quito.gob.ec` / `Ciudadano123`.

- [ ] Reservar cupo y consultar Mis inscripciones.
- [ ] Registrar o cancelar una inscripción de voluntariado.
- [ ] Enviar reporte con GPS y fotografía.
- [ ] Crear alerta comunitaria.
- [ ] Registrar situación de calle.
- [ ] Registrar alerta de violencia.
- [ ] Crear propuesta de obra con GPS.
- [ ] Crear reserva y comprobar que un horario duplicado sea rechazado.
- [ ] Solicitar permiso y adjuntar documento.
- [ ] Consultar obligaciones por cédula.
- [ ] Editar o cancelar solicitudes permitidas.
